# CLAUDE.md

`agent-docs/` is for documentation relevant mainly for the use of agents.

- `coding_standards.md` provides guidance on how agents should write high-quality effective Go code that matches our preferred styles.
- `conventions.md` covers project-level conventions (file paths, XDG, etc.).
- `plans/` holds per-milestone checklists + handoff protocol; read `plans/README.md` when resuming work.

See `STATUS.md` for current milestone and progress.
